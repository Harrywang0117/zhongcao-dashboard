# 种草软件

手机优先的个人种草决策库：快速保存大众点评、小红书、抖音等来源里的店铺/菜品线索，再整理、计划和记录轻反馈。

## 本地运行

```bash
npm start
```

打开 `http://localhost:4173`。

## 验证

```bash
npm test
```

## v1 已包含

- 收件箱快速保存、解析失败兜底、重新解析
- 快速整理为店铺、菜品、店铺 + 菜品、暂留线索
- 店铺/菜品列表与图列、搜索、默认标签和自定义标签
- 商圈、地址备注、时间段标签
- 日历按日期计划，支持改期、放回想去、不想去了
- 到店轻反馈：还想去、一般、不再去
- 回收站、封面图兜底、本地数据版本迁移
- 轻后端 `/api/link-preview`，不保存用户收藏数据
