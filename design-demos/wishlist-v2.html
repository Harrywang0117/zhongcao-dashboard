同一套内容、同一个「城市食册」方向，只改三件事：把首屏还给内容、把列表密度提上来、把「数据现在是两个人共享的」这件事画出来。强调色换回规格里原本定的椒红——深一档的 #C33C22 对白字 5.26:1，当前的琥珀是 1.86:1（源码注释里写的 2.15:1 还偏乐观），白字永远用不了。

这几张图在改什么

  • 首屏　想去页现在是「顶栏 78 + 搜索 52 + 三行 chip 150 + 排序行 44 = 324px 才看到第一条内容」。这里压到 153px（上图多出的 81px 是临时出现的远端提示条和一个已选筛选）。可用视口 660px 里，内容占比从 51% 到 77%。
  • 密度　行高 138 → 97px，缩略图 130 → 76px。首屏可见条数 2.2 → 5.2，滚起来之后 4.4 → 6.8。24 条的列表总长 3,600px → 2,330px，少滚三分之一。信息一条没少：名字、商圈、类型、时间、标签、添加人全在。
  • 添加人　从 76px 宽的「小王添加」胶囊缩成 22px 的字圆点。只有两个人，一个字就够认，省下的横向空间还给店名。
  • 共享状态　顶栏右侧常驻同步点（已同步 / 正在保存 / 离线）；对方改了东西时顶出一条可见的条，而不是现在这样悄悄把 remote state 换进来。
  • 强调色　椒红只出现在三处：主按钮、筛选计数、未处理提示。底栏选中改成墨色短条，日历 today 改成墨色描边——强调色遍地就不再是强调。
  • 形状　pill 只留给筛选和搜索；缩略图 12px、卡片与按钮 14px、标签 5px 方角。形状重新开始区分功能。
